## Description
Script for install packages and plugins on Linux.

## Platforms
Distribs:
- Arch-linux
- Ubuntu
Architecture:
- x86_64
- aarch64

## Packages and Plugins
1. Packages:
    1. [vim](https://www.vim.org)
    2. [mc](https://midnight-commander.org)
    3. [btop](https://github.com/aristocratos/btop)
    4. [fish](https://fishshell.com)
    5. [zellij](https://zellij.dev)
2. Plug-managers:
    1. [vim-plug](https://github.com/junegunn/vim-plug)
    2. [oh-my-fish](https://github.com/oh-my-fish/oh-my-fish)
3. Vim-plugins:
    1. [vim-fugitive](https://github.com/tpope/vim-fugitive)
    2. [vim-surround](https://github.com/tpope/vim-surround)
    3. [vim-airline](https://github.com/vim-airline/vim-airline)
    4. [vim-airline-themes](https://github.com/vim-airline/vim-airline-themes)
    5. [vim-gitgutter](https://github.com/airblade/vim-gitgutter)

## Installation
```sh
./install.sh
```
